# Text Cleaner

A Python-based text cleaning and preprocessing project.

## Project Overview

This project demonstrates a text preprocessing pipeline for cleaning user comments and preparing text for further analysis.

## Features

- Text cleaning and normalization
- HTML and special character handling
- Contraction expansion
- Stopword removal
- Word count calculation
- CSV input and output
- Cleaning success status

## Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Regular Expressions
- Jupyter Notebook
- Tkinter

## Project Files

- `Customer_input_data_cleaning_pipeline.ipynb` – Main notebook
- `clean_comments.py` – Text cleaning script
- `cleaner_gui.py` – Tkinter interface
- `input_comments.csv` – Sample input
- `cleaned_output.csv` – Processed output
- `Data_Cleaning_Report.docx` – Project report

## Installation

```bash
conda env create -f environment.yml
conda activate textcleaner_env
```

## Usage

Run the Jupyter Notebook or execute the Python cleaning script.
